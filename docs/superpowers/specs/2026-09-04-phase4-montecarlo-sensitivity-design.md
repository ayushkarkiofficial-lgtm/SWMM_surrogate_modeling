# Phase 4 Design — Monte Carlo + Sensitivity Analysis

**Date:** 2026-09-04
**Project:** SWMM surrogate modeling (see `PROJECT_BRIEF.md`)
**Phase goal:** Use the trained surrogates for large-scale Monte Carlo uncertainty analysis
(probabilistic flood outputs) and global sensitivity analysis (Brief §19–21).

## 1. Monte Carlo engine

- **N_MC = 50,000** samples; each of the 5 params drawn ~ **Uniform(training range)**,
  fixed `SEED = 42`. (Surrogate does 10k preds in ~12 ms, so 50k is ~60 ms; 100k trivial.)
- Load saved `models/*.joblib` (all XGBoost: peak regressor, flood classifier, volume
  regressor).
- **Hard two-stage flood outcome per sample:** `peak = peak_reg.predict(X)`;
  `flood = classifier.predict(X)` (prob > 0.5); `vol = flood ? volume_reg.predict(X) : 0`
  (clip negatives to 0).

Uniform inputs matching the training ranges means **every MC point is inside the
surrogate's learned domain** — trustworthy by construction, and a clean baseline for the
later AD phase.

## 2. Probabilistic outputs (Brief §20)

- **P(flooding)** = fraction of samples flooded.
- **Distributions** (histograms) + **percentile table** (mean, P50, P90, P95, P99) for peak
  discharge and flood volume (flooded subset).
- **Exceedance curves:** P(peak > x), P(flood_vol > v).
- **Headline statements:** P(flood); P(peak > {20, 25, 30} CFS); P(flood_vol > {5k, 10k,
  20k gal}); 95th/99th-percentile values.
- **Sanity check:** MC inputs match the training distribution, so P(flood) should land near
  the ~35% training rate and mean peak near ~19.5 CFS — confirms the MC is wired correctly.

## 3. Sensitivity analysis (Brief §21)

- **Permutation importance** for all three targets (peak / floods? / flood volume), computed
  on the labeled dataset — reveals whether infiltration & imperviousness matter more for
  *flooding* than they did for peak.
- **SHAP (TreeExplainer)** on the three XGBoost models: beeswarm (magnitude + direction),
  mean-|SHAP| bars, and a dependence plot for the top driver. Per-feature contributions and
  directions — the interpretability centerpiece.

## 5. Dependencies

- `pip install shap` (works with XGBoost via TreeExplainer). Everything else installed.

## 6. Success criteria

- P(flood) ≈ training flood rate (~35%) and mean peak ≈ 19.5 CFS (sanity passes).
- Coherent exceedance curves + a percentile table with defensible probabilistic statements.
- Sensitivity ranking consistent with physics (rainfall dominant for peak; infiltration /
  imperviousness more influential for flood volume) and consistent between permutation & SHAP.
